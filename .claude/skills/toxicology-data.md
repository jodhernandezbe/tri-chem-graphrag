# Toxicology Data Skill

## Toxicity Endpoints
- **Acute toxicity**: LD50, LC50, immediate health effects
- **Chronic toxicity**: Long-term exposure effects, NOAELs
- **Carcinogenicity**: Cancer classification, potency factors
- **Reproductive/developmental**: Teratogenicity, endocrine disruption

## Dose-Response Relationships
- Threshold vs non-threshold models
- Reference doses (RfD) and concentrations (RfC)
- Cancer slope factors and unit risks
- Uncertainty and safety factors application

## Data Sources Integration
- EPA IRIS database for reference values
- IARC cancer classifications
- OSHA/NIOSH occupational limits
- International toxicity databases

## QSAR Toxicity Modeling
- Structure-activity relationships for missing data
- Read-across methods for data-poor chemicals
- Model uncertainty and applicability domains
- Expert system integration

## Exposure-Health Relationships
- Population susceptibility factors
- Life stage considerations (children, elderly)
- Cumulative risk from chemical mixtures
- Environmental justice considerations

## Data Quality Assessment
- Study quality evaluation criteria
- Weight-of-evidence approaches
- Data gap identification and prioritization
- Regulatory guidance compliance

## Chemical Hazard Classification
- GHS classification system
- Hazard communication requirements
- Risk phrases and safety recommendations
- Regulatory status tracking
